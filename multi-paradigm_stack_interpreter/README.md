# Multi-Paradigm Stack Interpreter

A stack-based programming language implemented independently in Ruby,
Haskell, and Prolog.

## Implementations

### Ruby
Object-oriented implementation using dedicated classes for input
processing and stack execution.

### Haskell
Functional implementation based on recursive parsing, pattern matching,
and immutable stack transformations.

### Prolog
Logic-programming implementation using predicates, recursion, and
pattern matching to evaluate stack operations.

## Background

Originally developed as part of Advanced Programming Languages coursework
at Victoria University of Wellington.
