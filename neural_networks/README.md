# Neural Networks

A collection of Python and PyTorch projects developed at Victoria University of Wellington in 2025. The projects explore deep learning, neural network architectures, representation learning and generative modelling.

## Requirements

- Python 3
- PyTorch
- NumPy and Matplotlib
- Jupyter Notebook

## Projects

### Distribution Mapping

- Uses neural networks to learn transformations between probability distributions.
- Explores Gaussian-to-uniform mapping and loss functions such as Maximum Mean Discrepancy (MMD).

### Autoencoders

- Implements autoencoders and variational autoencoders (VAEs).
- Explores data compression, reconstruction and generative modelling using latent representations.

### Neural Differential Equations

- Explores transformations between probability distributions using neural differential equations.
- Investigates ordinary differential equations (ODEs) and stochastic sampling methods for generative modelling.

## Setup and Usage

Create and activate a Python virtual environment:

```bash
python -m venv .venv
source .venv/Scripts/activate
```

Install the required dependencies for the project being used.

Each project can be run independently using its Python scripts or Jupyter notebooks.

See the README in each project folder for specific setup instructions, implementation details and results.
